## Overview

This project demonstrates the application of fundamental Linear Algebra concepts on a student performance dataset. It shows how vectors, matrices, and transformations can be used to analyze data and extract meaningful insights.

The project bridges mathematical concepts with real-world data analysis using Python.

---

## Project Objective

The objective of this project is to:

- Represent data using vectors and matrices  
- Perform vector and matrix operations  
- Understand geometric interpretations (line, plane, hyperplane)  
- Apply matrix decomposition techniques  
- Perform dimensionality reduction using PCA and LDA  

---

## Dataset Description

- Rows represent students  
- Columns represent subjects  
- Each student is treated as a vector  

Example:
Student = [Math, Science, English, Computer]


---

## Part A: Vector and Matrix Fundamentals

- Represented students as vectors  
- Calculated L1 and L2 norms  
- Computed dot product and angle between vectors  
- Performed cross product (3D case)  
- Calculated projection of one vector onto another  

---

## Part B: Matrix Operations

- Represented dataset as matrix A  
- Performed matrix addition and multiplication  
- Used transpose operation  
- Calculated determinant  
- Computed matrix inverse  

---

## Part C: Linear Transformation and Geometry

- Explained line, plane, and hyperplane concepts  
- Performed linear combinations of vectors  
- Demonstrated feature expansion  

---

## Part D: Eigenvalues and Decomposition

- Computed covariance matrix  
- Found eigenvalues and eigenvectors  
- Applied LU decomposition  
- Performed Singular Value Decomposition (SVD)  

---

## Part E: Dimensionality Reduction

- Applied PCA to reduce dimensions  
- Applied LDA for classification
